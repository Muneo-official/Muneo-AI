## 읽는 법

- 범위 적중률이 목표 80%에 크게 못 미친다. 범위 폭 25%는 중간값 기준 위아래 약 12%인데 중간값이 보통 21~25% 어긋난다.
- 10건 중 7건이 과대다. 목공은 10건 모두 과대다. 범위 폭만 넓혀서는 부족하고 중간값도 고쳐야 한다.
- 부분 시공에서 크게 틀린 건은 공종의 일부만 시공했거나 창호 섹션이 도어뿐인 견적이다. 현재 입력으로는 구분할 수 없다.
- 리랭커는 전체 시공의 오차를 줄였지만 부분 시공과 과대 쏠림은 그대로다.
- 10건이라 구간이 넓다. 한 건이 움직이면 적중률이 10%p 바뀐다.

## 변경 이력

엔진을 바꿀 때마다 같은 10건으로 다시 재서 추가한다. 위 표(엔진 1.1.0)가 시작점이다.

### 엔진 1.2.0 — 총액 중간값을 참고 사례 중앙값으로 (2026-10-04)

총액의 "중간"을 범위의 중점으로 내보내서 참고 사례 중앙값보다 항상 높게 나오던 것을 고쳤다(전체 시공
+12.8%, 부분 시공 약 +7%). 전체 시공에서 마감비가 총액에 한 번 더 곱해지던 것도 없앴다. 범위(중간값에서
아래·위로 잡는 마진)는 바꾸지 않았다.

| 지표 (간접비 포함) | 리랭커 끔: 1.1.0 → 1.2.0 | 리랭커 켬: 1.1.0 → 1.2.0 |
|---|---|---|
| 절대 오차율 중앙값 | 25% → 26% | 21% → 18% |
| 범위 적중률 | 30% → 30% | 40% → 40% |
| 과대 / 과소 | 7 / 3 → 6 / 4 | 7 / 3 → 6 / 4 |
| 범위 폭 | 25% → 27% | 25% → 27% |
| 전체 시공 절대 오차율 / 적중률 | 23% / 33% → 13% / 33% | 16% / 50% → 13% / 50% |
| 전체 시공 과대 / 과소 | 4 / 2 → 3 / 3 | 4 / 2 → 3 / 3 |
| 부분 시공 절대 오차율 / 적중률 | 56% / 25% → 52% / 25% | 54% / 25% → 50% / 25% |
| 범위 적중률 — 직접비 기준 | 20% → 30% | 50% → 50% |

- 전체 시공의 오차가 줄고 과대 쏠림이 없어졌다. 과대였던 4건은 좋아졌고 과소였던 2건은 더 낮아졌다.
- 적중률은 그대로다. 범위를 건드리지 않았고, 중간값이 내려가면서 범위 안으로 들어온 건과 밖으로 나간
  건이 비슷했다.
- 범위 폭 27%는 범위를 넓힌 것이 아니다. 마진은 같고 중간값이 낮아져 비율이 커졌다.
- 부분 시공은 거의 그대로다. 전체 리모델링 사례가 참고되는 문제와 공종의 일부만 시공하는 문제가 남아 있다.
- 10건 전체의 오차율이 크게 줄지 않은 것은 부분 시공 4건이 그대로이기 때문이다.
- 마감/공과잡비 항목은 과소가 늘었다(10건 중 6건 → 8건). 3%가 실제 견적의 기타공사보다 낮다.
- 범위를 중간값 양쪽에 같은 폭으로 다시 잡는 안도 재 봤다. 전체 시공 적중이 한 건 늘지만(리랭커 끔
  33% → 50%), 참고 사례가 적을 때 최소가 중앙값보다 31~40% 낮아지고 위쪽 여유가 절반으로 줄어 택하지
  않았다. 코퍼스 총액은 이윤·보험료가 빠진 건이 많아 실제 견적이 더 높게 나오는 쪽이 흔하다.

### 엔진 1.3.0 — 부분 시공 요청에 부분 시공 사례 우선 (2026-10-04)

부분 시공 요청의 참고 사례가 대부분 전체 리모델링이라 공종 금액이 높게 나오던 것을 고쳤다. 서울·경기·인천
사례 중 부분 시공은 약 17%이고, 같은 공종이라도 평당 금액이 전체 리모델링보다 훨씬 낮다(목공·전기·철거는
약 0.35~0.4배, 창호는 약 0.2배).

- 부분 시공 요청이면 같은 지역·평수 조건으로 후보를 넉넉히 가져와 부분 시공 사례만으로 먼저 찾는다.
- 부분 시공 사례가 8건 미만이거나, 좁힌 뒤 요청 공종의 금액이 3건 미만인 공종이 있으면 기존처럼 전체 사례로 찾는다.
- 지역 조건은 풀지 않는다. 풀면 서울 요청이 다른 지역의 부분 시공 사례 가격으로 나온다.
- 요청이 "부분"이어도 공종 구성이 전체 리모델링과 같으면(도배·바닥·욕실 포함, 6개 이상) 좁히지 않는다.
- 공종이 없는 요청(리스크 진단의 가격 비교)과 전체 시공 요청은 달라지지 않는다.

| 부분 시공 4건 (공사비 기준, 리랭커 끔) | 1.2.0 | 1.3.0 | 참고 사례 |
|---|---|---|---|
| 공종 일부만 시공한 건 | +209% | +209% | 부분 시공 사례가 4건뿐이라 적용 안 됨 |
| 창호가 도어뿐인 건 | +75% | +35% | 부분 시공 사례 11건 |
| 도어뿐 + 일부만 시공한 건 | +49% | +49% | 부분 시공 사례가 2~3건뿐이라 적용 안 됨 |
| 플래그 없는 건 | −7% | −5% | 부분 시공 사례 15건 |
| 절대 오차율 중앙값 | 62% | 42% | |
| 범위 폭 중앙값 | 32% | 30% | |

- 4건 중 2건에 적용됐고 그 2건이 좋아졌다. 나머지 2건은 부분 시공 사례가 부족해 그대로다.
- 범위 폭은 넓어지지 않았다. 기준을 3건으로 두면 4건 중 3건에 적용되지만(가장 크게 틀린 건이 +209% →
  +100%) 참고 사례가 3~4건으로 줄어 범위 폭이 32% → 52%로 넓어져 8건으로 정했다.
- 적중률은 25%로 그대로다.
- 공종별(리랭커 끔): 가구 118% → 90%, 창호 85% → 61%, 전기/조명 30% → 23%. 목공은 여전히 과대 쪽이다
  (10 / 0 → 9 / 0).
- 남은 과대는 공종의 일부만 시공했거나 창호가 도어뿐인 건으로, 입력으로 구분할 수 없다.
- 효과는 부분 시공 사례 수에 묶여 있다. 사례가 늘면 적용되는 요청이 늘어난다.

검색 정확도(precision@15, 24개 쿼리, 297건 전량 라벨): 94.3%(이전 93.2%). 24개 쿼리 중 공종 구성이 부분
시공인 5개만 영향을 받았고, 새로 골라진 37건을 라벨링해 `labels.csv`에 추가했다(평수 차이 6평까지 관련 있음으로
