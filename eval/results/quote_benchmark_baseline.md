# 가견적 채점 기준선 (개선용 10건)

엔진을 고치기 전의 수치다. 이후 변경은 이 표와 비교한다.

- 측정일 2026-10-03, 엔진 1.1.0, 보정계수 1.1.0, 벡터 후보 풀 40
- 대상: 정답셋 개선용(dev) 10건 — 전체 시공 6, 부분 시공 4 (서울·수도권)
- 실행: `python -m eval.quote_benchmark` (리랭커 켬은 `USE_RERANKER=true`)
- 채점 중인 견적과 같은 의뢰의 사례는 검색에서 제외
- 평가용(eval) 20건은 실행하지 않음 — 마지막 LLM 비교 때 한 번만 실행

## 총액

| 지표 | 리랭커 끔 | 리랭커 켬 |
|---|---|---|
| 범위 적중률 — 간접비 포함 (95% 구간) | 30% (10~60%) | 40% (10~70%) |
| 범위 적중률 — 직접비 기준 (95% 구간) | 20% (0~50%) | 50% (20~80%) |
| 절대 오차율 중앙값 — 간접비 포함 | 25% | 21% |
| 절대 오차율 중앙값 — 직접비 기준 | 30% | 30% |
| 전체 시공 절대 오차율 / 적중률 | 23% / 33% | 16% / 50% |
| 부분 시공 절대 오차율 / 적중률 | 56% / 25% | 54% / 25% |
| 과대 / 과소 | 7 / 3 | 7 / 3 |
| 범위 폭 | 25% | 25% |

- 오차율: (엔진 중간값 − 실제 금액) / 실제 금액
- 범위 적중률: 실제 금액이 최소~최대 안에 든 건의 비율. 목표는 80%
- 범위 폭: (최대 − 최소) / 중간

## 읽는 법

- 범위 적중률이 목표 80%에 크게 못 미친다. 범위 폭 25%는 중간값 기준 위아래 약 12%인데 중간값이 보통 21~25% 어긋난다.
- 10건 중 7건이 과대다. 목공은 10건 모두 과대다. 범위 폭만 넓혀서는 부족하고 중간값도 고쳐야 한다.
- 부분 시공에서 크게 틀린 건은 공종의 일부만 시공했거나 창호 섹션이 도어뿐인 견적이다. 현재 입력으로는 구분할 수 없다.
- 리랭커는 전체 시공의 오차를 줄였지만 부분 시공과 과대 쏠림은 그대로다.
- 10건이라 구간이 넓다. 한 건이 움직이면 적중률이 10%p 바뀐다.
